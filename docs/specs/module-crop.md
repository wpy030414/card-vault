# 卡面检测与裁切模块规格

## 目标

用户只负责拍照，系统自动找到画面中最大的、最像卡片的圆角矩形，拉正为正面视角；用户可以微调。

## 处理流程

1. **准备**：`prepareImage(file)` 读入图片，限制最长边 2400px，画布铺白底（处理透明 PNG）。
2. **检测**：缩放到最长边 480px。
   - 灰度 + Sobel 边缘强度。
   - 取 88 分位阈值，膨胀 2 像素。
   - 8 连通域标记，过滤过小区域。
   - 每个区域求凸包与旋转卡尺最小外接矩形（min-area rect）。
   - 评分 = 面积占比 + 矩形周长覆盖率 + 长宽比接近 0.716 + 角点稳定性。
   - 返回四角、置信度、面积占比、是否自动。
3. **回退**：没有可靠候选时，返回内缩 5% 的矩形，并把 `auto` 标为 false。
4. **手动调整**：`CropEditor` 允许拖动四个角或整体平移；实时显示三分线与遮罩。
   - 用户保存的自定义裁切模式列在「整图」右侧；点击即把四角替换为该模式的归一化落点。
5. **拉正**：`warpCrop(prepared, quad)`。
   - 求单位正方形 → 四边形的单应矩阵。
   - 对输出每个像素做逆变换采样，双线性插值。
   - 与白色合成处理透明边缘。
   - 最长边限制 1600px，JPEG 质量 0.9。
6. **下一步**：正面完成后如存在背面，继续走同一流程；最后进入题名与日期。

## 界面

- 顶部步骤条：选图 → 裁切 → 题名。
- 裁切页显示「正面/背面」，不显示「自动识别 · xx%」或「手动框选」徽标。
- 工具栏：重新识别、整图，以及「整图」右侧按保存顺序排列的自定义模式按钮；当前生效的模式高亮。
- 工具：上一步、下一步。
- 忙碌时显示遮罩与 spinner，禁止重复提交。
- 移动端底部按钮右对齐且等宽。

## 验收

- 合成照片中 9° 倾斜的卡片被识别为四边形，拉正后四角亮度明显高于背景。
- 识别失败仍可手动拖动、使用整图或套用自定义模式。
- 套用模式后四角立即落到保存的相对位置，再「下一步」得到的成片与该模式的比例一致。
- 正面必填；背面可选；取消裁切可返回上一步。
- 损坏图片不会进入裁切步骤。
