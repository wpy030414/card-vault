# 自定义裁切模式模块规格

## 目标

同一拍摄位置下反复拍卡时，四角在画面里的相对落点通常一致。用户只需在一张示例照片上框一次四角并命名保存，之后同类照片在裁切页一键套用，不再重复拖动。

## 数据

`crop_presets`：

- `id`：UUID
- `user_id`：外键，级联删除
- `name`：1–24 字符
- `quad`：归一化四角 JSON 文本，顺序固定为左上、右上、右下、左下；坐标范围 `0..1`
- `created_at`：毫秒时间戳

只保存落点，不保存示例照片本身，因此模式数据很小、也不占用图片配额。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/crop-presets` | 当前用户的模式，按创建时间倒序 |
| POST | `/api/crop-presets` | 创建；校验名称与四角 |
| DELETE | `/api/crop-presets/:id` | 只能删除自己的模式 |

### 校验

- 名称去空白后非空且不超过 24 个字符。
- 四角必须是 4 个有限数字坐标，且都位于 `[0,1]`。
- 四个角按顺序必须围成凸四边形，面积至少为全图的 0.2%，防止退化或自交。
- 每个用户最多保存 60 个模式。

## 界面

- 主页右上角菜单 →「自定义裁切模式」打开管理弹窗。
- 列表展示模式名称、四角示意图与占画面比例；空状态说明用途。
- 「新建模式」：输入名称 → 选择一张示例照片 → 拖动四角 →「保存模式」。
- 删除需要二次确认；删除模式不影响已经收入的卡片。
- 裁切页中，模式按钮出现在「整图」右侧；当前套用的模式以高亮表示，手动拖动后取消高亮。
- 模式按归一化坐标直接套用，因此可以跨不同像素尺寸、不同宽高比的照片复用。

## 验收

- 新建模式后刷新页面，模式仍在。
- 裁切页点击模式后四角立即落到保存的相对位置；生成的图片宽高比与模式圈出的区域一致。
- 非本人模式不可读取、不可删除。
- 非法四角（越界、少于四个、面积过小、自交）返回 400，不会入库。
