# 手牌环与端详模块规格

## 视觉模型

- 牌环平面**平行于屏幕**，不是 3D 圆柱。
- 牌心位于以 `(50%, pivotY)` 为圆心、半径 `R` 的圆弧上；每张牌绕自身中心旋转相同的圆心角，像一只手捏着扑克牌。
- `pivotY ≈ 97%` 视口高度；圆心在屏幕下缘之外。
- 卡宽最大 300px（窄屏 70vw），可视槽位：窄屏 5、桌面 7。卡片多于槽位时进入循环队列，转动时从两侧隐藏区进出。
- 按槽位从左到右叠放，右侧牌压住左侧牌；不强制中心牌在最上层。
- 槽位边界在最外侧牌外半格：离场牌沿弧线滑出并淡出，入场牌从另一侧淡入。
- 背景绘制同半径的虚线圆与柔和光晕，提示「这是一圈牌」。

## 交互

| 手势 | 行为 |
| --- | --- |
| 横向拖动 | 牌环跟手旋转，速度用于惯性 |
| 快速甩动后松手 | 指数摩擦减速，低于阈值后吸附 |
| 轻点正在转动的牌环 | 立即吸附到最近一张 |
| 轻点静止的卡片 | 打开端详 |
| 从卡片向上拉 | 出现拖拽预览；超过阈值打开端详，牌环下沉淡出 |
| 悬停 / 键盘 | 卡片可聚焦，Enter/Space 打开端详 |

- 单张卡片时禁用横向旋转。
- 卡片上的按钮、输入框等交互元素不触发舞台指针逻辑。
- 手机端打开端详后的 380ms 内忽略合成 click，避免误翻面。

## 几何参数

```
idealSpan = 桌面 96° / 窄屏 30°
step = clamp(idealSpan / (min(count, maxSlots) - 1), 桌面 14°–26° / 窄屏 10°–18°)
R = pivotY - 顶部留白 - cardH / 2
```

- 桌面 `R ≈ 520px`，手机 `R ≈ 450px`；卡面占满屏幕主要区域，两侧牌可自然出血。
- 吸附目标为 `step` 的整数倍。
- 底部中央只显示 `当前/总数` 数字进度，例如 `1/100`；不显示操作指南。
- 右下角新增入口是纯圆形按钮。
- 主页右上角是菜单按钮：点击弹出对话层，提供「自定义裁切模式」与「退出登录」；退出登录仍需二次确认。
- 品牌不使用字母缩写徽记：启动页是一枚卡牌扇形叠放的线描徽记，卡背是同族的花窗纹样。

## 端详

- 卡片按正面宽高比展示，最大 430px 宽。
- 只保留卡片、标题、日期、左上角菜单与右上角关闭；不显示动作按钮长条。
- 轻点卡面翻面；无背面时卡片小幅来回翻转（摇头），不弹出文字提示。
- 左上角菜单提供编辑（标题/日期/镀层）与删除（确认后缩小淡出）。
- 指针移动让卡片轻微 3D 倾斜；桌面鼠标位置同时驱动彩光。
- 背景为暖粉半透明模糊层；牌环向下位移、缩小、模糊并淡出。
- 退出端详只有两条路径：右上角关闭按钮，或键盘 `Esc`；点击卡片周围的空白背景不再关闭，避免误触丢失阅读位置。
- 支持 `Esc` 关闭、`F` 翻面、`H` 触发彩光。
- 从牌山打开端详时，以源卡中心、宽高与角度做 0.95s 的旋转/平移/缩放过渡。
- 新卡入场有 0.95s 的升起、去模糊与淡入；添加后牌环平滑转到新卡。

## 彩光

- 仅 `holo = 1` 的卡片渲染彩光；未开启镀层的卡面不出现任何光膜。
- 开启时：`opacity ≈ 0.36` 的细斜纹彩带 + 跟随光斑，`mix-blend-mode: color`。
- 光斑位置来自 `--hx/--hy`：
  - `deviceorientation`：`gamma/beta` 归一化并低通平滑；
  - 桌面：指针在卡面上的位置。
- 摇一摇进入 `is-holo`：彩光增强、卡片轻微摆动 2.4 秒；无镀层的卡片不响应。
- 彩光层随 `.examine-flip` 一起旋转，翻面后仍覆盖在背面之上。
- iOS 在首次触碰卡面时申请体感权限，不显示单独按钮。

## 验收

- 拨动后角度改变，停驻后落在步长整数倍。
- 上滑打开端详；手机轻点卡片不会立即翻面。
- 体感授权后，倾斜手机使 `--hx/--hy` 改变。
- 卡片顺序与总数在旋转后保持一致，不重复、不丢失。
