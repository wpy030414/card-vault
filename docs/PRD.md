# CardVault 产品需求

## 1. 目标

做一个**只属于自己**的卡牌收藏展示应用：登录后能把手头喜欢的卡片拍照入库，并以有收藏感的方式陈列、端详。它不解决交易、估值、社交或云端共享。

## 2. 用户与场景

- **收藏者**：收到一张新卡，想随手拍照收进自己的匣子。
- **端详者**：想安静地一张张看卡，翻到背面，转动手机看镭射彩光。
- **换手机/长期使用**：希望数据留在自己的服务端文件里，不依赖第三方云盘。

## 3. 核心需求

### 3.1 登录与访问控制

- 登录页只呈现一个 QQ 扫码入口，不展示产品介绍长文。
- 未登录用户不能看到收藏匣，也不能调用卡片、图片接口。
- QQ 扫码直连腾讯网页登录，服务端拿到唯一 QQ 号作为身份；无需配置 QQ 应用。
- 本地开发可用 `DEV_AUTH=1` 直接进入；生产必须关闭。

### 3.2 收录卡片

- 选择一张照片（正面必填，背面可选），系统自动识别画面中最大的近似圆角矩形。
- 自动识别的四角可拖动微调；「整图」一键取全幅；右侧列出用户保存的自定义裁切模式，点一下即落到相同的相对位置。
- 确认后执行透视拉正、白底合成、限制最长边 1600px 的 JPEG。
- 填写标题、日期与「镀层」开关（默认为关）后入库；数据写入 SQLite。

### 3.3 手牌环

- 所有卡片在**屏幕平面**内排成一段圆弧，像一只手拿着扑克牌；不得使用 3D 圆柱/透视环绕。
- 快速横向拨动可以让牌环转动，松手后有惯性并吸附到某张牌。
- 轻点正在转动的牌环让它停下并吸附。
- 向上拉动某张牌，牌环下沉淡出，卡片从牌山位置旋转、放大过渡到端详大卡。
- 底部只显示「当前/总数」数字进度，不显示操作指南。
- 卡片数量多于可视槽位时，其余卡片在不可见区域排队；离场/入场沿弧线滑出并淡出，不瞬间消失。
- 右下角新增入口是纯圆形按钮。

### 3.4 自定义裁切模式

- 用户常有大量同一拍摄位置、同一裁切策略的照片：在一张示例照片上框好四角并命名保存。
- 保存的是四角在图片里的**相对位置**（归一化坐标），与示例照片的像素尺寸无关。
- 之后拉正同类照片时，模式作为快捷按钮出现在「整图」右侧，点一下即自动落好四角，不需要重复拖动。
- 模式随账号持久化在 SQLite 中；可新建、查看与删除。
- 主页右上角改为菜单：点击弹出对话层，提供「自定义裁切模式」与「退出登录」两个入口。

### 3.5 端详、编辑与彩光

- 端详时只保留卡片、标题、日期、左上角菜单与右上角关闭；不显示动作按钮长条。
- 退出端详只认右上角关闭按钮与 `Esc`；点击周围空白不退出。
- 除输入框外，界面不提供文本选中与长按选中，触摸端也不弹系统选词菜单。
- 轻点卡面翻面（有背面时）；无背面时卡片轻轻摇头，不弹出文字提示。
- 左上角菜单提供「编辑」（标题、日期、镀层）与「删除」（二次确认，卡片缩小淡出）。
- 只有开启**镀层**的卡片才覆盖一层**低透明度**的镭射彩光；未开启的卡面保持干净。
- 手机转动时，彩光的光斑位置随陀螺仪变化；桌面端鼠标移动同样驱动。
- 摇一摇时，开启镀层的卡片短暂变形、彩光增强；iOS 在首次触碰卡面时申请体感权限。

## 4. 验收标准

| 编号 | 验收 |
| --- | --- |
| A1 | 未登录访问 `/api/me`、`/api/cards`、`/media/*` 均返回 401 |
| A2 | 开发登录后刷新页面仍保持会话，退出后会话立即失效 |
| A3 | 登录页只显示一个 QQ 扫码标题与二维码，不出现营销长文 |
| B1 | 斜放在桌面上的卡片照片能被自动识别，拉正后四角都是卡面而非背景 |
| B2 | 正反面都能入库，端详时翻面看到对应图片 |
| B3 | 刷新后藏品仍在；两次点击删除后卡片与图片都消失 |
| B4 | 保存自定义裁切模式后刷新仍在；裁切页「整图」右侧出现该模式，点击后四角落到保存的相对位置 |
| B5 | 主页菜单可进入「自定义裁切模式」与「退出登录」；退出仍会二次确认 |
| C1 | 拨动牌环后角度改变，停驻后角度落在步长整数倍 |
| C2 | 上滑能打开端详；手机轻点卡片不会立即误触翻面；端详菜单可编辑/删除 |
| C3 | 体感授权后，倾斜手机使 `--hx/--hy` 改变，光斑随之移动 |
| D1 | 390×844 手机视口无横向滚动，牌环与操作区域可用 |
| D2 | 新建卡片默认无镀层、端详时无彩光；开启后彩光立即出现并可随时关闭 |

## 5. 非目标

- 不做卡片识别、估价、交易、社区、排行榜。
- 不做多用户共享、公开主页或云端同步。
- 不做原生 App；以移动浏览器体验为准。
